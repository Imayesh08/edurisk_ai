# 🎓 EduRisk AI — Explainable Machine Learning for Early Prediction of Student Academic Risk
**Course**: 19MAM56 Advanced Machine Learning Lab (Continuous Assessment Test II)

## 🌟 Overview
EduRisk AI is an end-to-end, reproducible, explainable machine learning research framework designed to detect academic underperformance early without target leakage.

- **Live Cloud Docker App**: [https://edurisk-ai-docker.onrender.com](https://edurisk-ai-docker.onrender.com)
- **GitHub Repository**: [https://github.com/Imayesh08/edurisk_ai](https://github.com/Imayesh08/edurisk_ai)
- **Hugging Face Space**: [https://huggingface.co/spaces/Imayeshh/edurisk-ai](https://huggingface.co/spaces/Imayeshh/edurisk-ai)

## 📊 Highlights
- **Leakage Prevention**: Strictly eliminates downstream grade leakage ($G_2$, $G_3$), evaluating solely on pre-period sociodemographic and period 1 indicators.
- **Explainability**: Integrated SHAP (SHapley Additive exPlanations) values for global feature impact and individual student predictions.
- **Model Benchmark**: Logistic Regression, Random Forest, LightGBM, and Tuned XGBoost evaluated against rigorous metrics (Recall, PR-AUC, ROC-AUC, Brier score).
- **Ethics & Fairness**: Subgroup fairness audits across gender, rural vs. urban schools, and family support systems.
- **Publication Artifact**: Full 10-page IEEE research paper included in `reports/final_report.pdf`.
